## The problem

Calls, screen sharing and file transfer between people on the same network, with no server and no internet connection.

## What I built

LanSymphony is a desktop app in Python that connects two people on a local network directly. We built it live at the Windsurf × The AI Collective OpenBuild in Bengaluru, as a team of two, and it placed 2nd. We then kept going and published it as **ZeroConnect**.

- **At OpenBuild (Aug 2025):** HD video calling with Picture-in-Picture and quality settings, voice, screen sharing and file transfer, all over one TCP connection between two peers, in a CustomTkinter interface.
- **As ZeroConnect (Nov 2025):** automatic peer discovery over UDP broadcast, encryption with Fernet (AES-128 in CBC mode with an HMAC-SHA256 check) for chat, files and voice under a key derived with PBKDF2, file transfers up to 100 MB, and an optional assistant that runs a local model through Ollama.

## Key decisions

<Decisions>
  <Decision
    title="Peer-to-peer with discovery by broadcast"
    why="With no central server there is nothing to host and nothing that needs the internet. Each peer announces itself on the network every 3 seconds, so the others can list it without typing an address."
    tradeoff="Broadcast only reaches the local network: connecting across the internet would need NAT traversal, which the app does not do."
  />
  <Decision
    title="A shared passphrase instead of a key exchange"
    why="Both peers derive the same Fernet key with PBKDF2, so a connection needs no handshake and works the moment two peers find each other."
    tradeoff="Every peer must share the same passphrase, and anyone holding it can read the traffic. A key exchange per session would remove that."
  />
  <Decision
    title="Encrypt chat, files and voice; stream video and screen as they are"
    why="Messages, files and audio are small enough to encrypt on every send without hurting the call."
    tradeoff="Video and screen frames cross the network unencrypted, so anyone on the same network could see them."
  />
</Decisions>
