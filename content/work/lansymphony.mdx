## The problem

Communication that works on a local network with no server and no internet connection, and stays private while doing it.

## What I built

LanSymphony is a serverless, internet-free communication system for local networks, written in Python with sockets and multi-threading. I built it live at the Windsurf × The AI Collective OpenBuild in Bengaluru.

- **Security and discovery:** AES-256 encryption and automatic peer discovery, on a multi-threaded architecture.
- **Calls:** HD video calling, VoIP audio and screen sharing, with customisable quality and Picture-in-Picture.

## Key decisions

<Decisions>
  <Decision
    title="Peer-to-peer with automatic discovery"
    why="With no central server there is nothing to host and nothing that needs the internet. Peers find each other on the network by themselves."
    tradeoff="Every client carries the networking logic, and peers have to discover each other without help."
  />
  <Decision
    title="AES-256 for everything on the wire"
    why="Other devices on a shared local network can see its traffic. Encryption keeps the conversation private."
    tradeoff="Encrypting every frame costs CPU, which matters most for real-time video."
  />
  <Decision
    title="A multi-threaded architecture"
    why="Video, audio and screen sharing run at the same time and shouldn't block one another."
    tradeoff="Threads bring synchronisation and shutdown complexity that a single loop avoids."
  />
</Decisions>
